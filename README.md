## Project Description
This project is a basic personal professional portfolio website
created as part of Week 1 of the DG Interns Hub Web Development
Internship.

The website demonstrates the fundamentals of HTML, including
semantic HTML structure, navigation, lists, tables, images,
links, and forms.
